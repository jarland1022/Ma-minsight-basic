# Console languages (i18n)

MA-MinSight Community ships with a **lightweight English-default UI**. Users can switch to Chinese in the browser.

## Defaults

| Surface | Default | Switch |
|---------|---------|--------|
| GitHub `README.md` | English | [README.zh-CN.md](../README.zh-CN.md) |
| Web console | English | Header / login: **EN \| 中文** |
| Ant Design components | Follows console language | `antd/locale/en_US` or `zh_CN` |
| API OpenAPI description | English | — |

Language preference is stored in `localStorage` under `ma_minsight_lang` (`en` | `zh`).

## Implementation

```text
web/src/i18n/core.ts          # getInitialLang (default en), persistLang
web/src/i18n/en.ts / zh.ts    # message catalogs
web/src/i18n/I18nProvider.tsx # t() helper
web/src/components/LanguageSwitch.tsx
```

Fallback: missing keys in Chinese fall back to English strings.

## Contributing more strings

1. Add keys under both `web/src/i18n/en.ts` and `zh.ts`.  
2. Replace hardcoded UI text with `t("section.key")`.  
3. Keep GitHub README English-first; put Chinese in `README.zh-CN.md`.
