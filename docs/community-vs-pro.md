# 社区版与专业版

社区版放在 GitHub / Gitee，让人能在自己的机器上把 Wazuh 告警**收进来、降噪、聚成事件**。专业版卖的是 **AI 深度研判 + 企微协作 + 防御闭环 + 有人负责**，不是再卖一套「能列表显示告警」的 UI。

## 定价（建议）

| 项目 | 建议 |
|------|------|
| 社区版 | 免费，Apache-2.0 |
| 专业版 | **¥9,800 / 节点 / 年**（可按合同调整；对标 SOC 工具而非纯开源捐赠） |
| 试用 | 由厂商签发限时 `license.lic`（社区仓库**无**自动 72h Pro 宽限） |
| 更高档 | 多节点、驻场调优、私有化 SOP 包另议 |

社区版装上后，导入有效 License 即可在同一套代码上解锁 Pro，无需重装。

## 为什么这样切

社区版必须能**自己装上、看到告警变少、事件列表有数据**，否则没有 Star，也没有咨询。专业版必须锁住 Agent 与企业协作，否则开源之后没有付款理由。

## 获客路径

1. README + Compose 让人 15 分钟跑通入库→初筛→聚合。
2. 文章讲清「SIEM 发现、MinSight 分诊」，挂 GitHub/Gitee 双链。
3. 控制台 License 页放指纹、联系方式与升级说明。
4. 试用 License 只从销售侧签发；**私钥与 `license_gen` 永不进本仓库**。
5. 中文内容（Wazuh 告警太多怎么办）比空仓库更容易被搜到。
