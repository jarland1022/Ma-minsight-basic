## P1 — 下周做（内容获客）

1. 注册 https://medium.com 或 https://dev.to  
2. 粘贴 [`medium-devto-article.md`](medium-devto-article.md)  
3. CTA：GitHub + WhatsApp / email  
4. Tags：`security` `soc` `siem` `wazuh` `opensource`

4. 标题别写价格；有人问再给 repo

1. [`demo-video-script.md`](demo-video-script.md) 或 Loom  
2. 描述放 GitHub + WhatsApp
